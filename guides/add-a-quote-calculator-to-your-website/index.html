How to add a quote calculator to your website, Instagram and Google profile

Step-by-step: add an instant quote calculator to WordPress, Wix, Squarespace and other website builders with one line of code, or share it as a link on Instagram, Facebook and Google.

By Liam Hockley, AiEngineered. Updated 24 October 2026.

Short answer: paste one line of embed code into an HTML or embed block on the page where you want the calculator, or share the calculator’s link anywhere customers find you. If you don’t have a website at all, the link works on its own.

What you need

Your calculator comes with two things: a link (a web address you can share) and an embed code, which looks like this:

<iframe src="https://…your calculator link…" width="100%" height="900" style="border:0" title="Instant quote calculator" loading="lazy"></iframe>

The embed code shows the calculator inside a page of your own website. The link opens it as its own page.

WordPress

  1. Edit the page where you want the calculator (a “Get a quote” or “Prices” page works well).
  2. Add a Custom HTML block.
  3. Paste the embed code, then update the page.

Wix

  1. Open the page in the Wix editor.
  2. Add an Embed Code element (Embed HTML) and paste the code.
  3. Stretch the element to full width and make it tall enough to show the whole calculator, then publish.

Squarespace

  1. Edit the page and add a Code block.
  2. Paste the embed code and save.

Some Squarespace plans don’t allow code blocks. If yours doesn’t, add a button that links to your calculator instead.

Other website builders

Most builders (GoDaddy, Shopify, Webflow and others) have an “HTML”, “Embed” or “Custom code” block. Paste the embed code there. If you can’t find one, use a button that links to your calculator.

Instagram, Facebook and Google

  • Instagram: edit your profile and add the calculator link to your links, so it shows in your bio.
  • Facebook: add the link as your page’s website, or to the action button on your page.
  • Google Business Profile: add the link as your website, or as your booking link if your business category offers one.
  • Vans, flyers and cards: turn the link into a QR code so people can scan it.

Where to put it

Put it where people decide whether to contact you: a “Prices” or “Get a quote” page, near the top of your home page, and as the main link on your social profiles. One clear call to action, such as “See your price in 30 seconds”, works better than several competing ones.

Common questions

Do I need a website to use a quote calculator?

No. The calculator has its own link, which works in an Instagram bio, a Facebook page, WhatsApp messages or as a QR code on vans and flyers.

Will an embedded calculator slow my site down?

An embed only loads when the page with it is opened, and you can put it on its own page so the rest of your site is unaffected.
